## Projects

**[ForgeOrder](https://github.com/Sagar02k4/forgeorder)**
Order-processing service built around the hard parts of checkout: atomic inventory reservation without overselling, idempotent requests, payment reconciliation for uncertain outcomes, signed webhooks, and a transactional outbox publishing to RabbitMQ. Uses a mock payment gateway, built as a learning project.
`Java 21` `Spring Boot` `PostgreSQL` `RabbitMQ` `Redis` `Docker` `Testcontainers`

**[Task Scheduler API](https://github.com/Sagar02k4/task-scheduler)**
Backend that resolves task dependencies and schedules by priority. Uses DFS for cycle detection, topological sort and Kahn's algorithm with a priority queue, plus deadline-conflict detection and JWT auth. [Live API docs](https://task-scheduler-7ial.onrender.com/swagger-ui/index.html)
`Java 21` `Spring Boot` `JWT` `PostgreSQL` `Docker` `JUnit`

**[TradeOpenEnv](https://github.com/Sagar02k4/TradeOpenEnv)**
Reinforcement learning trading agent built on an OpenEnv-style environment, with a custom reward function and an interactive analytics dashboard. [Live demo](https://huggingface.co/spaces/Syndicater69/TradeOpenEnv)
`Python` `Reinforcement Learning` `Gradio` `Plotly` `Hugging Face`

**[MindTabs](https://github.com/Sagar02k4/mindtabs)**
Chrome extension that tracks open tabs, lets you tag your intent for each one, and reminds you to revisit them. Syncs across devices. [Live](https://mindtabs.vercel.app)
`JavaScript` `Chrome APIs` `Supabase`

**[ASCIILens](https://github.com/Sagar02k4/ASCIILens)**
Turns your webcam feed into ASCII art in real time, using a C++ core compiled to WebAssembly with a React front end. [Live](https://dist-eight-omega-14.vercel.app/)
`React` `C++` `WebAssembly`

Also: [Claude Code clone in Java](https://github.com/Sagar02k4/codecrafters-claude-code-java) and [Shell in Java](https://github.com/Sagar02k4/codecrafters-shell-java), built from scratch through CodeCrafters.
